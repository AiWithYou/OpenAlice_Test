# OpenAlice 日本株・米国株・ETF対応版

このフォークは、上流の最新版を基に、日本語を既定言語として日本株・米国株・ETFを同じマーケット画面とAI検索から扱えるよう調整したものです。

## 対応範囲

- 日本株: 東証コードをそのまま検索できます。
  - `7203` または `7203.T` — トヨタ自動車
  - `130A` または `130A.T` — 英数字を含む新しい東証コード形式
- 米国株:
  - `AAPL`、`MSFT`、`NVDA` など
- 米国ETF:
  - `SPY`、`QQQ`、`VTI` など
- 東証ETF:
  - `1306` または `1306.T` など
- 既存対応:
  - 暗号資産、為替、商品、市場指標、ファンダメンタルズ、ニュース、ブローカー連携

ETFはYahoo Financeの銘柄種別判定を使って株式と分離します。価格履歴は株式と共通のOHLCV取得経路を利用しますが、画面、検索結果、URL、ウォッチリスト上では `ETF` として保持されます。

## 起動

Node.jsとpnpmを用意したうえで実行します。

```bash
git clone https://github.com/AiWithYou/OpenAlice_Test.git
cd OpenAlice_Test
git switch master
pnpm install
pnpm dev
```

開発ブランチを確認する場合は、対象ブランチへ切り替えてから同じ手順で起動します。

```bash
git switch agent/sync-jp-us-etf-20260716
pnpm install
pnpm dev
```

ターミナルに表示されたURLをブラウザで開きます。通常は `http://localhost:5173` です。

## マーケット検索

マーケット画面の検索欄では、会社名より銘柄コードを使う方が確実です。

| 対象 | 入力例 | 内部シンボル |
| --- | --- | --- |
| 日本株 | `7203` | `7203.T` |
| 英数字の東証銘柄 | `130A` | `130A.T` |
| 米国株 | `AAPL` | `AAPL` |
| 米国ETF | `SPY` | `SPY` |
| 東証ETF | `1306` | `1306.T` |

検索結果でデータ提供元を選択した場合、その `barId` を保持したまま詳細画面へ移動します。ETFの価格履歴は内部で株式OHLCV経路へ変換されるため、ETFのURL・表示種別を失わずにチャートを取得できます。

## AIへの依頼例

```text
7203とAAPLの直近1年の値動きを比較して
```

```text
SPY、QQQ、1306.Tを比較し、構成と値動きの違いを整理して
```

```text
日本株コード130Aを検索して、利用できる市場データを確認して
```

AIの統合市場検索は `equity`、`etf`、`crypto`、`currency`、`commodity` を区別して返します。実際に売買できる契約を探す場合は、マーケットデータ用シンボルではなくブローカー側の契約検索を使用します。

## 注意点

- Yahoo Financeなど外部データ提供元の仕様変更や一時的な障害により、検索や価格履歴が取得できない場合があります。
- データ提供元の価格は遅延していることがあります。画面上の提供元とデータ品質表示を確認してください。
- ブローカー連携・注文機能は上流と同様に開発途上です。調査用途から開始し、実売買では注文内容と銘柄IDを必ず確認してください。
